# Carbon development rules

- Use `Pumpkin-ref` inside this Carbon folder as a high-level reference for each milestone. Check its license and any file-specific notices before considering reuse.
- Carbon is an original GPL-3.0-only implementation. Do not copy, translate, or closely adapt Pumpkin server source, tests, or assets. Its main project declares GPL-3.0; separately licensed components and third-party data require their own review. Attribution does not remove license obligations.
- Prefer reference documentation, observable behavior, public specifications, and independently designed Carbon code/tests. Record the references consulted and limitations in `REFERENCE_POLICY.md`.
- Preserve existing user changes and reference files. Run formatting, workspace tests, and Clippy after implementation changes.
